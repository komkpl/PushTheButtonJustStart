# Just Start

押すとカウントダウンが始まるだけのアプリ。Push the button. Just start.

## 最小版（Webページ）

`web/` に、スマホのホーム画面に置いて使うWebページがある。

画面は数字とボタンだけ。ボタンを押すと「カチッ」と音が鳴り、カウントダウンが始まる。

- 分数は初期値25分（ポモドーロ）。数字をタップすると、分数（1〜99）を入力できる
- アプリを閉じても動き続け、開き直すと続きが表示される
- 動いている間はボタンが押し込まれたままになり、軽く押しても止まらない（分数も変えられない）。止めたいときはボタンを1秒長押しする。押している間はボタンの外周の枠が上の真ん中から時計回りに伸び、一周すると止まる。途中で離すと枠は戻り、タイマーはそのまま動き続ける
- 0になっても音は鳴らない。ボタンが戻り、0を1秒見せたあと開始時の表示（25:00 など）に戻る。また押すだけで始められる

一度開けば、オフラインでもすぐ起動する（Service Worker）。

iPhoneでは、消音モードのときは「カチッ」が鳴らない。

### 手元で動かす

```bash
python3 -m http.server 8765 --directory web
```

ブラウザで http://localhost:8765 を開く。

### スマホのホーム画面に置く

HTTPSで公開したURLをスマホで開き、ホーム画面に追加する。

- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「ホーム画面に追加」

オフライン起動はHTTPSか localhost でしか動かない。同じWi-FiのMacから http で配信したURLでもホーム画面には置けるが、Macが止まっていると開けない。

### 更新するとき

開いたときはキャッシュ済みの版をすぐ出し、裏で新しい版を取りに行く。そのため変更が見えるのは、更新後2回目に開いたとき。`web/` にファイルを足したら、`web/sw.js` の `FILES` に加え、`CACHE` の版番号を上げる。
