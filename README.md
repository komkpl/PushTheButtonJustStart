# Just Start

押すとカウントダウンが始まるだけのアプリ。Push the button. Just start.

## Webアプリ

公開URL：https://komkpl.github.io/PushTheButtonJustStart/

気に入ったら [Buy Me a Coffee](https://buymeacoffee.com/komkpl) で応援してもらえるとうれしいです。

- `web/index.html`：紹介ページ（ランディングページ）。何のアプリかの説明と、アプリへの入口
- `web/app/`：アプリ本体。スマホのホーム画面に置いて使う

ホーム画面から起動された紹介ページは、すぐ `app/` に移る。以前はトップにアプリがあったので、そのころ追加したアイコンもそのまま使える。

画面上の切り替えで、2つのモードを選べる。ボタンを押すとカウントが始まり、「カチッ」と音が鳴る。開いたときは 5 sec が選ばれている（分数のタイマーが動いているときは、その続きを表示する）。

- **5 sec**：5秒のカウントダウン。マリオカートのスタートのように、3〜1で低い音、0で高い音が鳴る
- **分数（初期値 25 min）**：数字か、選択中の「25 min」をタップして時間（分と秒、最大 99:59）を入力する。一般的なタイマーと同じく、数字は右から入る（2→5→0→0 で 25:00、4→5 で 00:45、消すと右から1桁ずつ戻る）。開いた直後は全体が選ばれていて、最初に打った数字から入れ直しになる。音は鳴らさず、0になっても何も起こらない。アプリを閉じても動き続け、開き直すと続きが表示される

動いている間はボタンが押し込まれたままになり、軽く押しても止まらない（モードと分数も変えられない）。止めたいときはボタンを1秒長押しする。押している間はボタンの外周の枠が上の真ん中から時計回りに伸び、一周すると止まる。途中で離すと枠は戻り、タイマーはそのまま動き続ける。

どちらのモードも、0になるとボタンが戻り、0を1秒見せたあと開始時の表示（5 や 25:00）に戻る。また押すだけで始められる。

一度開けば、オフラインでもすぐ起動する（Service Worker）。

iPhoneでは、消音モードのときは音が鳴らない。

### 手元で動かす

```bash
python3 -m http.server 8765 --directory web
```

ブラウザで http://localhost:8765 （紹介ページ）か http://localhost:8765/app/ （アプリ）を開く。

### スマホのホーム画面に置く

公開URLの `app/` をスマホで開き、ホーム画面に追加する。

- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「ホーム画面に追加」

オフライン起動はHTTPSか localhost でしか動かない。同じWi-FiのMacから http で配信したURLでもホーム画面には置けるが、Macが止まっていると開けない。

### 更新するとき

アプリは、開いたときはキャッシュ済みの版をすぐ出し、裏で新しい版を取りに行く。そのため変更が見えるのは、更新後2回目に開いたとき。アプリで使うファイルを足したら、`web/app/sw.js` の `FILES` に加え、`CACHE` の版番号を上げる。

`web/sw.js`（トップのService Worker）は、旧版を入れていた端末の後片付け専用。古いキャッシュを消して自分の登録を外すだけなので、消さずに残しておく。
